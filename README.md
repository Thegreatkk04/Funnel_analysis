#  E-Commerce Funnel Analysis & Power BI Dashboard

## Overview

This project analyzes an e-commerce customer journey using Python and Power BI. The objective is to understand customer behavior across different funnel stages, identify drop-off points, measure conversion performance, and build an interactive business dashboard for decision-making.

---

## Objectives

- Analyze customer movement through the sales funnel
- Calculate conversion rates between funnel stages
- Identify high-performing marketing channels
- Compare device, region, and product category performance
- Analyze daily and hourly trends
- Build an interactive Power BI dashboard
